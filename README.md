# История России: история и философия науки и технологий

Открытый учебный курс по **истории науки и техники** в 30 занятиях
(15 осенних + 15 весенних), построенный на **верифицированном корпусе
источников** и подготовленный для работы с ИИ-агентом
([botai](https://github.com/visualcomments/botai)) как соучеником/сокурсником.

Базовая программа — рабочая программа дисциплины «История России:
история и философия науки и технологий» (2025 г.). Все оригинальные
материалы курса распространяются по лицензии **GNU GPL v3**.

## Что в репозитории

| `tools/` | Инструменты для агента: поиск по корпусу (локально/удалённо), RAG-API, верификация, материалы и задания занятия, статус |

## Индекс и эмбеддинги на Google Диске

Индекс корпуса (Annoy + эмбеддинги + чанки, ~86 МБ архив) распространяется
через **Google Диск** — репозиторий самодостаточен:

```bash
make index-fetch URL="https://drive.google.com/file/d/FILE_ID/view?usp=sharing"
#   → скачает архив, проверит SHA-256, развернёт в COURSE_CORPUS_ROOT/index/
make search QUERY="Ньютон"        # поиск по локально установленному индексу
```

Состав архива, контрольные суммы и порядок обновления — в
`docs/GOOGLE-DRIVE.md`; готовый манифест — `index-manifest.example.json`.

## Работа с агентом (botai)

Репозиторий адаптирован под harness [botai](https://github.com/visualcomments/botai):
чистый **AGENTS.md** (инструкция агенту), машиночитаемый `syllabus.json`,
трек `agents/courses/history-science/track.md`, навык
`using-course-corpus` (в `.agents/`, `.claude/`, `.cursor/`), готовые
инструменты поиска и проверки цитат. Подробный цикл — в
`docs/AGENT-WORKFLOW.md`; быстрый старт для агента — в `AGENTS.md`.

## Быстрый старт (человек)

```bash
make help                 # список целей
make assignment n=18      # вопросы и задания занятия 18
make session n=18         # материал занятия 18 (текст + цитаты + источники)
```

Цитаты проверяются автоматически (`make verify` → `verification/REPORT.md`).
Поиск по корпусу — локальный (после `make index-fetch`, см. `docs/GOOGLE-DRIVE.md`).

## Источники и проверка

Курс опирается на корпус текстов публичного достояния
(классические труды по истории математики, физики, биологии, химии,
техники; документы NASA и доклады о науке и технологиях США — public
domain). Каждая прямая цитата в лекциях дословна и снабжена координатами
«файл · фрагмент #N»; отчёт проверки — `verification/REPORT.md`.
Подробности — `CORPUS.md` и `citations.md`.
