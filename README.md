# История и философия науки и технологий

**Открытый учебный курс для студентов 4 курса  ** (-школа
авиационных и цифровых технологий), построенный на основе рабочей программы
дисциплины «История России: история и философия науки и технологий»
(РУП 2025, руководитель курса — канд. ист. наук А. С. Клемешов).

Курс — **оригинальное произведение**: авторский текст лекций, каждая
содержательная линия опирается **только на проверенные источники из
верифицированного корпуса** (публичное достояние, см. `verification/`).

## Что внутри

| Раздел | Содержание |
|---|---|
| `syllabus.md` | Программа курса: 12 модулей, связь с РУП, балльная карта |
| `lectures/` | 12 лекций в Markdown, с цитациями и вопросами |
| `verification/` | Скрипт и отчёт проверки **каждой** цитаты по корпусу |
| `citations.md` | Правила цитирования и список источников корпуса |

## Принципы курса

1. **Только проверенный корпус.** Каждая прямая цитата в лекциях взята
   дословно из файла корпуса (`txt/…`); соответствие автоматически проверяется
   скриптом `scripts/verify_quotes.py` (см. `verification/REPORT.md`).
2. **Ссылки на фрагменты.** Каждая цитата сопровождается указанием файла и
   номера фрагмента (chunk) в индексе корпуса — фрагмент можно открыть через
   поиск по RAG (`scripts/rag_search.py`).
3. **Оригинальность.** Интерпретации, связки и примеры — авторские; цитаты
   используются как свидетельства источников, а не как «наполнение».
4. **Профильные темы .** Отдельные модули посвящены истории
   аэродинамики и инженерной механики, электромагнетизма — радиолокации,
   вычислительной техники — беспилотных систем; они встроены в общую
   хронологию курса.

## Как устроен корпус

Курс опирается на локальную библиотеку (каталог, файлы `txt/`, RAG-индекс
`index/`). Карта соответствия «модуль → файлы корпуса» — в `citations.md`.
Проверка цитат: `python scripts/verify_quotes.py` (вывод —
`verification/REPORT.md`).

## Быстрый старт

```bash
# посмотреть лекцию
open lectures/01_metodologiya.md
# проверить цитаты курса по корпусу
python scripts/verify_quotes.py
# семантический поиск по корпусу (пример: найдём фрагменты про Ньютона)
.venv/Scripts/python.exe scripts/rag_search.py "Математические начала Ньютона" -k 5
```
