# Лицензии и провенанс новых источников (дополнение корпуса 2026-09-12)

Этот файл реестрирует происхождение и лицензии источников, добавленных в
корпус курса «История науки и техники» сверх прежнего состава
(см. PROVENANCE.md). Правило включения: только общественное достояние (PD)
или свободная лицензия (CC0 / CC-BY / CC-BY-SA). «Открытый доступ без
лицензии» и коммерческие/подписочные издания НЕ включались.

## 3. Что сознательно НЕ включено

- **OAPEN-книги** (Directory of Open Access Books) — хотя по определению это
  OA-книги под CC, у большинства записей поле `dc.rights` пустое, а уточнение
  лицензии через Crossref требует поштучной проверки DOI. Часть релевантных
  (Golden Years of Australian Radio Astronomy, Open Skies — CC-BY 4.0 по
  Crossref) может быть добавлена отдельным шагом.*
- **Современные книги Internet Archive** post-1923 (абонемент/borrow-only) —
  не PD, не включены.
- **LibGen и аналоги** — вне рамок корпуса.

(*В этот заход мы добавили к статьям Wikipedia и PD-первоисточникам только те
OAPEN-книги, для которых лицензия CC-BY подтверждена без неоднозначности;
число таких среди отобранных топ-тем невелико, см. catalog/oapen_candidates.json.)
