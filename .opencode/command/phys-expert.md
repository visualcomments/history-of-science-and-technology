Запусти первое экспертное задание для эксперта в модуле
`physics-dataset-competition` в режиме **«агент делает работу, эксперт
валидирует результат»**.

Действуй по агенту `phys-expert` и
`physics-dataset-competition/docs/EXPERT-GUIDE.md`:

1. Один раз спроси согласие и параметры: домен (`AERO`/`STR`/`RADAR`/`CTRL`),
   тема (можно пусто) и короткий латинский slug (можно сгенерировать).
2. Запусти один оркестратор, который делает всю цепочку сам:
   `python physics-dataset-competition/scripts/run_assignment.py --domain ... --query ... --slug ... --service all --limit 15 --target-records 3 --retrieved-at "<ISO>"`
   (поиск → авто-фильтр прав → lawful-загрузка → авто-извлечение → сборка →
   выборочная проверка → схемный валидатор → `validation-bundle.json` →
   HF dry-run/PR).
3. Покажи участнику компактную таблицу из `validation-bundle.json` и спроси
   **одно** подтверждение: числа из авто-извлечения — черновик, эксперт
   проверяет единицы/знаки/условия по первоисточнику.
4. При замечаниях — исправление через `scripts/correct.py` (append-only) и
   повторная проверка. После подтверждения — dry-run, затем Hub PR (`--publish`,
   `HF_TOKEN` только из окружения).

Если оркестратор вернул `blocked`/недостаточно источников — сообщи
`blocked: <причина>` и не выдумывай данные.

Дополнительный ввод участника (если есть): $ARGUMENTS
