# Спецификация датасета, метаданные и шаблон лицензии

Датасет модуля обязан быть **машиночитаемым, верифицируемым и юридически
прозрачным**. Эта спецификация — чек-лист для каждого выложенного датасета.

## 1. Структура репозитория датасета (в Kaggle-пакете и в каталоге команды)

```
data/
  <slug>.csv                  # основные данные (UTF-8, разделитель , или ;)
  <slug>.parquet              # (опционально) колоночный формат
raw/                          # сырые выгрузки и пруфы извлечения
README.md                     # метаданные (см. ниже)
DATASET-LICENSE.md            # заявление о лицензии (шаблон, см. ниже)
baseline.ipynb                # базовая обработка/метрика (Kaggle noteboook)
validation/                   # результаты автоматической и ручной сверки
```

## 2. Схема колонок (минимальный каркас; домен — свой)

Поля общие для любого датасета модуля:

| Колонка | Тип | Обязат. | Пояснение |
|---|---|---|---|
| `source_book` | str | да | Точное название книги (издание, год) |
| `source_scan` | str | да | Где взят скан: Internet Archive id / URL / файл корпуса |
| `source_ref` | str | да | Страница и/или «файл · фрагмент #N», номер таблицы |
| `variable` | str | да | Измеряемая величина (словами) |
| `value` | float | да | Числовое значение (в исходных единицах) или `null` при пропуске |
| `unit` | str | да | Единица (м, км/ч, МГц, м/с, л/с, град и т.п.) |
| `condition` | str | нет | Условия измерения (угол атаки, высота, частота …) |
| `notes_transcriber` | str | нет | Пометки транскрибатора (что исправлено, OCR-предупреждения) |
| `quality` | enum | нет | `exact`/`ocr-review`/`estimated` |

Единицы — **только международные предпочтения**; если источник в других
единицах, добавьте столбец `unit_source` и `conversion_note`.

## 3. README-метаданные (обязательные поля)

1. `title` и `version`;
2. `license` (`CC0-1.0` или `PDDL`), и если не CC0 — текст разрешения;
3. `source_types`: «книга в общественном достоянии», «архивный скан (IA)» и
   ссылки;
4. `terms`: краткое «Исходные тексты — в общественном достоянии; данные —
   факты, авторским правом не охраняются; сбор и проверка выполнены командой
   (список имён); датасет публикуется как Public Domain/CC0»;
5. `how_to_cite`: пример цитирования;
6. `provenance`: какой этап модуля и кто (git log в каталоге команды).

## 4. Шаблон заявления о лицензии (`DATASET-LICENSE.md`)

```markdown
# Лицензия датасета: <название>
Версия 1.0 · дата · команда: <имена>

1. Содержимое (числовые данные и измерения) — это факты; в соответствии с
   законодательством факты и данные не охраняются авторским правом
   (ГК РФ ст.1259 п.5; в США — прецедент Feist v. Rural, 1991). Сама по себе
   числовая часть набора не является объектом авторских прав.
2. Исходные книги, из которых извлечены данные, находятся в общественном
   достоянии: <перечень: автор, годы жизни, год издания, аргумент срока>
   (источник сканов: <IA/URL>).
3. Сбор, проверка и нормализация выполнены <командой>; сформированная база
   публикуется как **CC0-1.0 (Public Domain)** / **PDDL**, т.е. без
   ограничений, с атрибуцией источника в качестве вежливости.
4. Атрибуция по строкам сохранена в колонках source_* для проверяемости.

Дополнительно: <ссылки на правовой анализ модуля 10-legal-public-domain.md>
```

## 5. Правила валидации перед публикацией

- [ ] Каждая строка имеет `source_*` (никаких «случайных» строк без источника);
- [ ] Значения согласованы с источником (выборочная сверка ≥ 5 %, зафиксирована);
- [ ] Нет значений-фабрикаций и «скопируй-и-подправь» без пометок;
- [ ] Единицы объявлены; конвертации задокументированы;
- [ ] Авточеки: без пустых обязательных полей, дубли(по `source_ref+value`) сняты;
- [ ] README заполнен по п.3, файл лицензии по п.4;
- [ ] В карточке Kaggle выбрана лицензия `CC0-1.0`/`PDDL`.
