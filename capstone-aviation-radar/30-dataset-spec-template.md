# Спецификация набора данных, метаданные и шаблон лицензии

Набор данных модуля обязан быть **машиночитаемым, проверяемым и юридически
прозрачным**. Эта спецификация — перечень обязательных требований.

## 1. Раскладка каталога набора

```
data/
  <название>.csv               # основные данные (кодировка UTF-8, разделитель , или ;)
  <название>.parquet           # (необязательно) колоночный формат
raw/                           # сырые выгрузки и улики извлечения
пояснительный файл (README)     # метаданные (см. ниже)
файл лицензии (LICENSE)         # заявление о лицензии (шаблон, см. ниже)
эталонный блокнот               # базовый разбор и метрика
проверка/                       # результаты автоматической и ручной сверки
```

## 2. Схема столбцов (общий каркас; наполнение — по вашей области)

| Столбец | Тип | Обязателен | Пояснение |
|---|---|---|---|
| `source_book` | текст | да | Точное название книги (издание, год) |
| `source_scan` | текст | да | Источник скана: библиотека/адрес/файл корпуса |
| `source_ref` | текст | да | Страница и/или «файл · фрагмент #N», номер таблицы |
| `variable` | текст | да | Измеряемая величина (словами) |
| `value` | число | да | Значение (в исходных единицах) или «нет данных» при пропуске |
| `unit` | текст | да | Единица (м, км/ч, МГц, м/с, л/с, град и т. п.) |
| `condition` | текст | нет | Условия измерения (угол атаки, высота, частота и т. п.) |
| `notes_writer` | текст | нет | Пометки того, кто вносил данные (исправления, предупреждения) |
| `quality` | выбор | нет | `точно`/`требует проверки распознавания`/`оценка` |

Единицы — предпочтительно единые; если источник в других единицах, добавьте
столбцы `unit_source` и `conversion_note`.

## 3. Пояснительные метаданные (обязательные поля)

1. название и версия;
2. лицензия (`CC0-1.0` или `PDDL`);
3. тип источника: «книга в общественном достоянии», «архивный скан (библиотека)»,
   ссылки;
4. краткие условия: «Исходные тексты — в общественном достоянии; данные —
   факты, авторским правом не охраняются; собраны и проверены командой
   (имена); набор публикуется как общественное достояние (CC0)»;
5. как цитировать;
6. происхождение: этап модуля, автор (журнал изменений в каталоге команды).

## 4. Шаблон заявления о лицензии

```markdown
# Лицензия набора данных: <название>
Версия 1.0 · дата · команда: <имена>

1. Содержимое (числовые данные и измерения) — это факты; в соответствии с
   законодательством факты и данные не охраняются авторским правом (в РФ —
   п. 5 ст. 1259 ГК РФ; в США — прецедент Feist v. Rural, 1991). Числовая
   часть набора не является объектом авторских прав.
2. Исходные книги, из которых извлечены данные, находятся в общественном
   достоянии: <перечень: автор, годы жизни, год издания, обоснование срока>
   (источник сканов: <библиотека/адрес>).
3. Сбор, проверка и приведение к схеме выполнены <командой>; сформированный
   набор публикуется как **CC0-1.0 (Public Domain)** / **PDDL** — свободно, с
   атрибуцией источника в качестве вежливости.
4. Атрибуция по строкам сохранена в столбцах source_* для проверки.

Дополнительно: ссылки на правовой анализ модуля `10-legal-public-domain.md`.
```

## 5. Требования проверки перед публикацией

- [ ] каждая строка имеет источник (`source_*`), нет «безликих» строк;
- [ ] значения согласованы с книгой (выборочная сверка не менее 5 %, зафиксирована);
- [ ] нет поддельных значений и «переночных» правок без пометок;
- [ ] единицы объявлены; пересчёты задокументированы;
- [ ] автоматические проверки: нет пустых обязательных полей, дубликаты по
  (`source_ref`+`value`) устранены;
- [ ] пояснительный файл заполнен по п. 3, файл лицензии по п. 4;
- [ ] в карточке Kaggle выбрана лицензия `CC0-1.0`/`PDDL`.
