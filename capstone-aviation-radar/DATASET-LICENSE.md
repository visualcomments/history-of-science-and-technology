# Лицензия датасета: <название датасета>

Версия 1.0 · Дата · Команда: <имена участников>

1. **Данные — это факты.** Содержащиеся числовые значения и результаты
   измерений являются фактами и, согласно законодательству, не охраняются
   авторским правом (в РФ — п. 5 ст. 1259 ГК РФ: правовая охрана не
   распространяется на факты; в США — прецедент Feist Publications v. Rural
   Telephone, 1991). Само по себе числовое содержимое набора не является
   объектом авторских прав.

2. **Исходные книги — в общественном достоянии.** Данные извлечены из
   изданий, которые перешли в общественное достояние:
   - <Автор, годы жизни> — «<Название>» (<год издания>); источник скана:
     <Internet Archive / файл корпуса / URL>.
   Расчёт статуса зафиксирован в правовом анализе модуля
   (`capstone-aviation-radar/10-legal-public-domain.md`).

3. **Сбор и проверка.** Сбор, транскрипция, нормализация и выборочная сверка
   выполнены студенческой командой <…> в рамках курса. Лицо, формирующее
   базу данных (изготовитель в смысле ст. 1333–1335 ГК РФ), добровольно
   отказывается от прав на этот набор, публикуя его в режиме общественного
   достояния.

4. **Условия распространения.** Набор публикуется под лицензией
   **CC0-1.0 (Public Domain Dedication)** — либо, для данных со ссылкой на
   атрибуцию, **PDDL (Open Data Commons)**; полный текст лицензии доступен на
   https://creativecommons.org/publicdomain/zero/1.0/ (или
   https://opendatacommons.org/licenses/pddl/). Использование свободно: без
   ограничений, с указанием источника в качестве вежливости.

5. **Атрибуция и прослеживаемость.** Каждая строка несёт происхождение
   (колонки `source_book`, `source_scan`, `source_ref`), чтобы исходную
   страницу и таблицу можно было проверить независимо.

6. **Границы.** Набор не включает охраняемые авторским правом современные
   тексты, изображения с отдельным копирайтом без пометки, данные
   ограниченного доступа или личные данные. Если вы обнаружили строку,
   вызывающую сомнения в правовом статусе, — сообщите организатору модуля,
   версия будет пересмотрена.
