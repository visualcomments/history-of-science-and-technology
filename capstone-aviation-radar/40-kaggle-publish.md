# Публикация датасета на Kaggle

Kaggle — платформа для датасетов, ноутбуков и соревнований. Датасеты
публиковать можно бесплатно; публикация проходит в разделе «Datasets».

## Шаги

1. **Аккаунт.** Зарегистрируйтесь на https://www.kaggle.com, подтвердите e-mail;
   при желании подключите Kaggle API (`kaggle.json`) для командной загрузки.
2. **Создание датасета.** «New Dataset» → New (загрузка) или Create: загрузите
   `data/`, `README.md`, `DATASET-LICENSE.md`, `baseline.ipynb`.
3. **Метаданные** (обязательно честно): название, теги (`aviation`, `radar`,
   `history-of-science`, `tabular`), описание (коротко про происхождение, срок
   PD, лицензию и как повторить транскрипцию), выберите **License**:
   `CC0-1.0` (рекомендуется для «общественное достояние данных») либо `PDDL`.
   Поле License вносится в карточку и является юридически значимым.
4. **README датасета** внутри — по спецификации (см.
   `30-dataset-spec-template.md`, раздел 3): license, source_types, terms,
   provenance, how_to_cite.
5. **Baseline-ноутбук.** «New Notebook» на странице датасета: минимальный код
   (pandas/pyarrow): чтение, проверка структуры, пара быстрых описательных
   статистик, заготовка под метрику соревнования. Save → Commit Version,
   затем «Public».
6. **Проверка.** Пройдите чек-лист из `30-dataset-spec-template.md`, раздел 5,
   и убедитесь, что на странице датасета видна выбранная лицензия и ссылка на
   исходники.

## Правовая прозрачность в карточке

В описание датасета добавьте блок:

> Исходные книги — в общественном достоянии (см. правовой анализ модуля).
> Данные — факты и результаты измерений, авторским правом не охраняются;
> сбор/проверка — команда <...>. Датасет опубликован как CC0-1.0 (Public
> Domain). Каждая строка содержит происхождение (source_book/source_scan/
> source_ref) для проверки.

## Ограничение по объёму и приватному контенту

- Не публикуйте охраняемые авторским правом тексты целыми кусками и личные
  данные; проверяйте датасет и файлы на соответствие Правилам сообщества
  Kaggle перед публикацией.

## Версии

При доработке «изменяйте» датасет (Edit → Save new version): в архиве курса
останется история версий с корректной лицензией.
