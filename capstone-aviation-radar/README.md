# Рабочий модуль: архивные данные по авиации и радиолокации → публикация на Kaggle

Учебное направление курса «История России: история и философия науки и
технологий». Слушатели учатся добывать **экспериментальные и табличные
данные из архивных книг, находящихся в общественном достоянии** (авиационные
и радиолокационные материалы), превращать их в аккуратные **наборы данных**,
публиковать их на платформе **Kaggle** и организовывать **учебное
соревнование от сообщества**. Обязательное условие — полная правовая
прозрачность; подробности в `10-legal-public-domain.md`.

## Схема работы

```
Архивная книга (общественное достояние)        → проверить правовой статус
   │        │ распознавание текста / ручная транскрипция
   │        ▼
таблицы, измерения, ряды значений          → «сырая» выгрузка (происхождение)
   │        ▼ приведение к единой схеме
лицензия «общественное достояние» (CC0/PDDL)   → готовый набор данных
   │        ▼
Kaggle: карточка набора + эталонный блокнот → публикация
   │        ▼
учебное соревнование сообщества (правила + метрика)
```

## Темы источников (примеры корпуса и открытых архивов)

- Радиолокация и электромагнитные волны: опыты Герца, таблицы длин волн,
  частот, затухания; ранние работы по радиолокационной проблематике;
- Аэродинамика и беспилотная авиация: продувочные таблицы профилей крыла,
  поляры, коэффициенты сопротивления, зависимость подъёмной силы от угла
  атаки;
- Баллистика, прочность, измерения скорости и дальности.

Главное правило: брать данные из книг, чей правовой статус подтверждён, а
сами числа и измерения — факты, которые авторским правом не охраняются.

## Этика и безопасность

- Только открытые книги в общественном достоянии; никаких недавних и закрытых
  материалов.
- Никакой подделки данных и «переноса» значений между источниками без пометки.
- У каждой строки есть происхождение (книга/издание/год/источник скана и
  координата «файл · фрагмент #N»/страница/номер таблицы).
- При публикации указывайте лицензию (`CC0-1.0` или `PDDL`) и атрибуцию
  источника; личные сведения не публикуются.

## Небольшой словарь терминов

Часть названий — служебные и собственные имена платформы и форматов, их
принято оставлять на английском; поясняем русскими словами:

| Термин | Русское пояснение |
|---|---|
| Kaggle | онлайн-платформа для задач анализа данных, наборов и соревнований |
| датасет / dataset | набор данных |
| baseline / эталонный блокнот | простое базовое решение, точка отсчёта для сравнения |
| notebook (Kaggle) | интерактивный блокнот с кодом |
| карточка (набора) | страница описания набора на Kaggle |
| лицензия CC0-1.0 / PDDL | открытые правовые режимы «общественное достояние» для данных |
| README | пояснительный файл «как пользоваться набором» |
| OCR | автоматическое распознавание текста со скана |
| CSV / Parquet | распространённые форматы файлов с данными |
| соревнование (competition) | учебное/соревновательное задание с правилами и метрикой |
