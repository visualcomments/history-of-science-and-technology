# Капстоун-модуль: архивные данные по авиации и радиолокации → Kaggle

Рабочее направление курса «История России: история и философия науки и
технологий». Студенты учатся добывать **экспериментальные и табличные
данные из архивных книг в общественном достоянии** (авиационная и
радиолокационная тематика), превращать их в аккуратные датасеты,
публиковать их на **Kaggle** и организовывать **соревнование от
сообщества**. Полная правовая прозрачность — обязательное условие: см.
`10-legal-public-domain.md`.

## Схема работы

```
Архивная книга (PD)                      → проверить правовой статус
   │         │ OCR / ручная транскрипция
   │         ▼
таблицы/измерения/ряды данных        → «сырая» выгрузка (происхождение)
   │         ▼ нормализация
лицензия CC0 / PDDL + README-метаданные → датасет
   │         ▼
Kaggle: Dataset + baseline-ноутбук   → публикация
   │         ▼
Community-соревнование (правила+метрика)
```

## Темы источников (примеры из корпуса и открытых архивов)

- Радиолокация / электромагнитные волны: опыты Герца, таблицы длин волн,
  частот, коэффициентов затухания; ранние советские работы по РЛС-проблематике;
- Аэродинамика и беспилотные авиационные системы: продувочные таблицы
  профилей крыла, поляры, коэффициенты сопротивления, экспериментальные
  зависимости подъёмной силы от угла атаки;
- Баллистика, прочность, измерения скорости и дальности.

Главное правило: брать данные **из текстов, чей правовой статус подтверждён**
(автор в общественном достоянии), а **сами числа и измерения** — это факты,
которые авторским правом не охраняются (см. правовой документ).

## Этика и безопасность (правила модуля)

- Никаких засекреченных/недавних военных материалов; только открытые PD-книги.
- Никакой фабрикации данных и «переноса» значений из одного источника в
  другой без пометки.
- Каждая строка несёт происхождение (книга/издание/год/IA-идентификатор,
  файл · фрагмент/page/номер таблицы), чтобы любой мог проверить.
- Публикуя на Kaggle, указывайте лицензию (CC0-1.0 или PDDL) и добавляйте
  атрибуцию источника; личные данные не публикуются.
