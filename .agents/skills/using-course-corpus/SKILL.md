# Skill: using-course-corpus

Работа с верифицированным корпусом источников курса «История и философия
науки и технологий» ( , РУП 2025).

## Когда применять

- когда нужно найти материал/цитату по любому сюжету курса (занятия 1–30);
- перед тем как дать обучающемуся объяснение, цитату или проверку задания;
- для подготовки эссе/реферата с обязательными ссылками на корпус.

## Процедура

1. **Получи корпус, если его нет.** Курс не готов к занятиям без
   установленного корпуса: без текстов цитируемый фрагмент нечем подтвердить.
   Если `python tools/status.py` показывает отсутствие корпуса — это первое
   действие занятия, а не отложенная просьба к обучающемуся:

   ```
   make corpus-fetch          # индекс + тексты, с проверкой SHA-256
   make corpus-status         # только отчёт, без загрузки
   ```

   Обязательны **оба** артефакта: индекс (поиск) и тексты (`txt/`, проверка
   цитат). Индекс без текстов фрагмент находит, но подтвердить его нечем.
   Мёртвую ссылку — сообщить сопровождающему курса; подставлять другую
   ссылку самостоятельно нельзя, как и собирать «свой» корпус из случайных
   источников: непроверенная подборка создаёт видимость доказательства.

2. **Локализуй корпус.** `python tools/status.py` покажет путь корпуса
   (`COURSE_CORPUS_ROOT`), число файлов, наличие RAG-индекса.
   Если корпуса нет — работай по `citations.md` и `verification/REPORT.md`,
   не выдумывая координаты цитат.
3. **Поиск.** `make search QUERY="..."` или
   `python tools/rag_search.py "..." -k 5 --json`. Ответ — фрагменты с
   координатами `file` + `chunk_id` (текст чанков в `index/chunks.jsonl`).
4. **Цитируй только так:**
   - дословный текст из фрагмента (OCR-нормализация: пробелы/переносы/ё-е;
     двойные слоги OCR допускается очищать);
   - источник: `txt/<файл>` · фрагмент #N;
   - покрытие цитаты в источнике ≥ 0.92 (проверяет `tools/verify_quotes.py`).
5. **Цитата на иностранном языке — с переводом.** Оригинал остаётся
   дословным (перевод проверить по корпусу нельзя), а рядом даётся русский
   перевод, помеченный как перевод:

   > «the original text, verbatim»
   > — перевод: русский перевод
   > `txt/<файл>` · фрагмент #N

   Переводи точно, а не красиво: оговорки автора («по-видимому») сохраняются.
   Перевод — ваша работа, а не слова автора; выдавать его за текст источника
   нельзя. Пропущенный фрагмент помечается «[…]», а не исчезает молча.
   Не переводятся: пути и имена файлов, координаты фрагментов, команды,
   переменные окружения, DOI/ISBN, оригинальная строка цитаты.

6. **Авторский синтез.** Если факт нельзя подкрепить цитатой корпуса —
   формулируй своими словами и помечай «вне корпуса»; не называй это цитатой.
7. **Проверка.** После правок с цитатами запусти `make verify` — отчёт
   `verification/REPORT.md`; расхождений быть не должно.

## Язык материала

Материал для обучающегося — по-русски: русская терминология вместо
английских слов, цитаты с переводом (пункт 5). Подробности — навык
`language-and-translation` в harness (botai). Сам корпус не переводится:
тексты источников хранятся в оригинале, перевод делается при подаче.

## Материалы занятия

- `make session n=<NN>` — `tools/session_material.py NN` (занятие + цитаты +
  источники);
- `make assignment n=<NN>` — `tools/assignment_brief.py NN` (вопросы и задания).

## Ограничения

- В репозитории курса лежат только карта источников и верификация; полные
  тексты корпуса и RAG-индекс — локально (см. `CORPUS.md`).
- Цитаты из современных (не публично-доступных) работ в корпус не включаются;
  профильные темы  (ИИ, БАС, радиолокация) опираются на документы
  public domain (NASA, доклады 2016/2019) — см. `citations.md`.
